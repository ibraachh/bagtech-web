Why is your website slow? 7 technical checks for speed and SEO

November 12, 20263 min readBagTech team

A large share of visitors open a website on a phone over mobile internet. If the page does not load within a few seconds, the visitor goes back. On top of that, Google takes page experience, including speed, into account in search results.

Contents

    How to measure speed

    The free Google PageSpeed Insights tool tests the mobile and desktop versions of a site and reports the Core Web Vitals: how quickly the main content appears (LCP), how quickly the page responds to clicks (INP) and whether elements shift out of place while the page loads (CLS).

    7 common causes

    1. Large images. A 4 MB photo is shown in a small card. Fix: serve images at the size needed, in WebP or AVIF format.
    2. Everything loads at once. Images and videos outside the screen load immediately too. Fix: lazy loading, that is, loading them only when they come into view.
    3. Too many scripts and plugins. Every extra widget makes the page heavier. Fix: remove the ones that are not used and defer the loading of the rest.
    4. No caching. The browser downloads the same files again on every visit. Fix: proper cache rules for static files.
    5. No CDN. All visitors connect to one distant server. Fix: a CDN such as Cloudflare serves files from a server close to the user.
    6. Fonts delay the appearance of text. Fix: load only the font weights you need and use "font-display: swap".
    7. Weak hosting or heavy queries. Fix: measure the server response time (TTFB) and, where necessary, optimise the server or the database queries.
    Even the most beautiful design goes unseen if people have to wait for it to load.

    Targets for the metrics

    Google considers the following thresholds "good" for Core Web Vitals:

    MetricWhat it measuresGood result
    LCPTime until the main content appears2.5 seconds or less
    INPHow fast the page responds to clicks200 ms or less
    CLSHow much elements shift while loading0.1 or less

    Quick wins you can do in a day

    • Compress your 10 largest images and convert them to WebP.
    • Switch off plugins and widgets that are not used.
    • Put the site behind a CDN and enable caching for static files.
    • Set the width and height on images so that the page does not "jump" while loading.

    After these steps, measure again with PageSpeed Insights: the difference often shows immediately. Deeper optimisation, such as reworking the code and the server, should follow a plan based on those measurements.

    How are speed and SEO linked?

    A fast site means more page views, fewer bounces and a higher conversion rate. The other basics of technical SEO should not be forgotten either: a unique title and description for every page, a correct heading structure (H1, H2), sitemap.xml and robots.txt, mobile-friendliness and structured data (schema.org).

    In short

    • Start by measuring with PageSpeed Insights.
    • The main causes are images, scripts and caching.
    • A CDN and correctly loaded fonts improve speed at low cost.
    • Speed is part of technical SEO.

    Frequently asked questions

    What are Core Web Vitals?

    Core Web Vitals are the three metrics Google uses to measure page experience: LCP (the time until the main content appears), INP (how fast the page responds to clicks) and CLS (how much elements shift while the page loads).

    Does website speed affect SEO?

    Yes. Google takes page experience into account in search results, and visitors leave a slow site sooner.

    What is a CDN?

    A CDN (Content Delivery Network) is a network that serves a site's files from the server closest to the user, which speeds up loading.
